## 💡 Key Learnings

### Two Sum
Started with the brute-force `O(n²)` approach and then optimized it using hashing to achieve `O(n)` average time.

### Contains Duplicate
Used an `unordered_set` to keep track of previously seen elements and detect duplicates efficiently.

### Best Time to Buy and Sell Stock
Learned to track the minimum price seen so far and calculate the maximum possible profit while traversing the array once.

### Check if Array Is Sorted and Rotated
Learned to treat the array as circular and count the number of positions where the increasing order breaks.
