## Key Learnings

- For #27, keep only elements that are different from the given value.
- For #169, the brute-force O(n²) approach caused TLE, leading to the O(n) Boyer-Moore approach.
- For #189, repeated rotation caused TLE, leading to the O(n) reversal approach.
- For #349, use nested loops to find common elements and `find()` to avoid duplicates.
